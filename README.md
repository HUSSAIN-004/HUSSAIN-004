## Featured Projects

### 🤖 AI Meeting Assistant
`Python` `LangChain` `OpenAI Whisper` `ChromaDB` `Streamlit`

AI-powered assistant that transcribes, analyzes, and summarizes audio, video, or YouTube recordings. Integrates Whisper (~90–95% transcription accuracy) and Sarvam AI for English/Hindi, with Mistral AI extracting decisions and action items. Includes a RAG chat interface over meeting context via ChromaDB, plus PDF/TXT export.

### 🚀 PrepWise AI — Placement Preparation Platform
`React` `Node.js` `Express.js` `MongoDB` `Gemini API` `OpenTDB API`

Full-stack placement prep platform with protected auth, dashboard analytics, DSA tracking, aptitude tests, and an admin dashboard. Gemini-powered resume analysis and mock interview feedback cut resume review time by ~70–80%.

### ⚡ VectorSpace Engine
`C++` `HNSW` `KD-Tree` `Ollama` `REST API`

A high-performance vector database built from scratch in C++, implementing HNSW, KD-Tree, and brute-force search — HNSW indexing cuts query latency by ~80–90% over brute-force on large datasets. Ships a fully local RAG pipeline via Ollama (768-dimensional embeddings) and a Web UI with live 2D PCA visualizations.

### 🧠 AI Codebase Copilot
`Python` `FastAPI` `SQLAlchemy` `JWT` `AI` `Vector Search`

AI-powered codebase assistant that scans Git repositories, generates vector embeddings, and enables intelligent code search and contextual Q&A using Retrieval-Augmented Generation (RAG). Features secure JWT-based authentication, repository management APIs, a modular FastAPI backend, and automated code chunking for scalable semantic retrieval.

### 🎗️ Breast Cancer Prediction
`Python` `Scikit-Learn` `Machine Learning`

ML classifier for benign vs. malignant tumor diagnosis, achieving 96–98% test accuracy to support early detection.

### 🏥 DocBook
`MongoDB` `Express.js` `React.js` `Node.js`

Full-stack appointment booking platform with user, doctor, and admin dashboards, authentication, doctor search, and booking workflows.
